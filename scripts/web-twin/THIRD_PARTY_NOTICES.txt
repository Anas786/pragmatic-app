Third-party notices for the PES 3D twin page (SldTwin/twinHtml.generated.js).

The page inlines the web portal's own compiled 3D twin. Its chunks contain
the open-source code below; the web build strips licence comments, so the
notices travel here, with every copy of the page (scripts/web-twin/build.mjs
puts this file and the Inter licence into the page as an HTML comment).
The twin and the SLD model library are Pragmatic Energy Solution's own code.
